# Herald

AI-powered changelog generator and release announcer CLI tool.

## Commands

- `bun install` - Install dependencies
- `bun run build` - Production build via tsup
- `bun test` - Run tests
- `bun run check` - Lint and format check via Biome
- `bun run check:fix` - Auto-fix lint and format issues

## Code Style

- Biome for linting and formatting
- TypeScript with Zod for schema validation
- Path aliases: `@/` maps to `src/`

## Notes

- Always use `bun` as the package manager, not npm or yarn
